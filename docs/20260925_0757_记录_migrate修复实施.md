## 5. 缩略语

- **AST**：Abstract Syntax Tree，抽象语法树（静态解析 import，不执行代码）
- **fork-and-own**：源代码复制进新仓、新仓拥有并继续演进的语义
- **full_copy / port_to_contract**：migrate 按「源有无 contract/」的二级分流（full_copy = 整套照搬源代码；port_to_contract = 套模板骨架 + 老资产进只读参考区）
- **contract / workspace**：承载口径（数据划分、指标、终评）的不可变目录 / agent 可改写目录
- **M0**：适配策略准备题（keep_all/hybrid/rewrite），step=0 不计入 27 步
- **migration-diff**：源项目现状 vs 答卷口径的差异表（`.auto-nn/migration-diff.json`，7 道源对齐题）
- **confirm_only / headless**：答卷覆盖全部计步题时的「只签字不逐题弹卡」模式 / 无人交互出仓
- **闭包检查**：check_copy_closure.py 对出仓产物内部 import 逐个验证目标文件存在
- **regen / TSV**：regen_results_tsv.py 重生成成绩表表头 / Tab-Separated Values 制表符分隔的成绩记录文件
- **skeleton / profile**：按范式（supervised/rl/physical）的演示骨架 / 范式档案
