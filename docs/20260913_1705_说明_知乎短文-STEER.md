**导语**：auto-research 不必换题，也不必收成一张公共榜。STEER 把你已经能跑的项目接进来，让 Agent 在治理体系下开放搜索：往哪搜、搜多深你定；改动和分数留下，这个结果认不认，也是你说了算。

近年来，auto-research 进入实验现场：由 Agent 修改训练代码、完成一轮训练、读取指标，再提出下一轮改动。现有工作大致沿两条路线展开。

一条是系统自带任务模板，覆盖从想法到论文的端到端流程。另一条是把任务收束为固定的小型训练练习，集中搜索训练实现。STEER 面向第三种情形：

**在研究者已有、且可以运行的项目上开展 auto-research。**

其设计要求以下三点同时成立：

- **课题与评价随项目进入。** 各项目保留自身的任务和打分方式，不并入一张公共榜。立项时写成只读合同：任务是什么、训练阶段可见哪些信息、官方分如何计算、单轮预算多久。官方测试从原项目继承，再予以冻结。
- **搜索保持开放，并由人指定方向与深度。** 不是只给出「去提分」，也不是把每一步允许的改动列成一张表。人指定搜索的方向和深度；Agent 在工作区中修改实现，连续多轮运行。
- **认定权不在 Agent。** 每一轮的改动、日志和分数写入成绩表，并走冻结后的官方测试。Agent 可以读取该测试，不能改写。搜索结束后进行复查，结果是否保留由人决定。若任务本身需要修改，只通过给人使用的通道提出，不能由 Agent 自行改写。

这就是 **STEER**（Steerable and Traceable autonomous Experimentation for Evidence-governed AI Research：可引导、可追溯、证据治理下的自主实验）。它是开源的 auto-research 实验框架，面向用 AI 做研究（AI for Research）：执行可以交给 Agent，任务、打分和认定不交给它。

## 一次实验怎么走

![STEER五步实验流程](https://rinshin-1256651400.cos.ap-beijing.myqcloud.com/images/2026/09/13/170526-flow-skills.png)

*图注：STEER 五步实验流程。源仓出分 → 立项把任务和打分写成合同 → 立朴素下界和公开对照 → 搜索（自动多轮或手跑）→ 审查复现、多种子，留不留你定。前半段把课题接进来并定边界，中间是人掌舵的开放搜索，最后认定在你这边。*

1. **先在这台机器上跑出一个分。** 用原项目原来的入口，不要直接抄论文数字。
2. **立项。** 把题、能看什么、怎么打分、一轮多久写成合同。后面 Agent 只能读。
3. **先立两把尺。** 一个「最傻但还能打分」的下界；再尽量在本机对齐一个公开方法。
4. **开始搜。** 手跑或自动连跑。你定风格（往哪搜、搜多深），Agent 改工作区、跑训练。
5. **复查。** 对当前最好做复现、多种子这类检查。**留不留，你说了算。**

日常在 Cursor 或 Claude Code 里用 `/auto-nn-*` 技能驱动。装好之后，对话里直接打斜杠命令即可。

## 开放探索长什么样：ABCDE

治理不是把搜索锁死。人掌舵，靠的是一张探索空间图：横轴是改哪一层，纵轴是改多深。

![STEER探索空间ABCDE](https://rinshin-1256651400.cos.ap-beijing.myqcloud.com/images/2026/09/13/174350-space-grid.png)

*图注：STEER 探索空间。横轴 A–D 是 Agent 可以改的层：训练、模型、目标、数据。纵轴是改多深：常规 → 派生 → 换法 → 自称新颖。右边 E 在格子外面，改题只能人点头。底下的条是探索风格：谨慎 / 优化 / 进取。绿点连线表示搜索常常先在训练和模型的浅层走动，再往上探。虚线是文献检查：可以声称走得深，但不等于发了新颖证书。*

人话对照：

| 格子 | 在改什么 |
|---|---|
| **A 训练** | 学习率、日程、配方这类训练策略 |
| **B 模型** | 网络结构、模块、表示 |
| **C 目标** | 损失函数、训练目标 |
| **D 数据** | 用什么数据、怎么采样和增强 |
| **E 改题** | 换任务定义或打分口径。Agent 只能报上来，不能自己改掉 |

纵轴四档也不神秘：还在已知做法里调，是常规；把已有零件重新搭，是派生；离开本项目现在的做法，是换法；声称新颖，必须过文献检查，且检查**不发证**。底下选风格，就是在这张图上定航向——谨慎多半先走训练浅层，进取才把目标、数据、更深的档打开。

所以「在治理体系下开放探索」不是口号：搜索空间是开的，航向是人定的，改题和判分不在 Agent 手里。

## 技能怎么用

安装后，在 Cursor 或 Claude Code 的对话里打 `/auto-nn-*`。一共 **17 个技能**，按实验顺序排，不需要一次记完。

日常就这几步：

| 你要干什么 | 打什么 |
|---|---|
| 把已有项目接进来 | `/auto-nn-init` |
| 立最傻的下界 | `/auto-nn-plain` |
| 立公开对照 | `/auto-nn-reference` |
| 自动连跑 / 手跑 | `/auto-nn-auto-run` / `/auto-nn-manual-run` |
| 复查当前最好 | `/auto-nn-audit` |

搜的时候随时可以看成绩、只读分析、或只想不训练：`/auto-nn-check`、`/auto-nn-analyse`、`/auto-nn-reflect`。想设目标分、写给人看的路线图，用 `/auto-nn-goal`、`/auto-nn-human-guidance`。

另外还有两类，不是每轮都点：改项目**允许做的事**（指标、场景、模型、损失）走 `/auto-nn-modify`；换机、拉模板、体检、清试跑、把过长记录收短，走 `/auto-nn-setup`、`/auto-nn-update`、`/auto-nn-doctor`、`/auto-nn-clear`、`/auto-nn-compress`。

技能把角色拆开：立项冻合同、搜索改实现、复查由人认定。Agent 不会在同一条命令里既改题又给自己判分。

## 上手

环境：Linux/macOS，Python 3.10+，Poetry，Cursor 或 Claude Code。

```bash
git clone https://github.com/xieyulai/steer.git
# 国内也可：https://gitee.com/xieyulai/steer.git
cd steer
./install.sh
```

然后在 Agent 对话里，对**你的训练仓路径**说（不要在模板目录里开训）：

```text
/auto-nn-init <你的仓库路径>
```

按提示把题和打分说清楚之后，在**旁边新开的项目**里依次：`/auto-nn-plain` → `/auto-nn-reference` → `/auto-nn-auto-run` 或 `/auto-nn-manual-run` → `/auto-nn-audit`。

细节见仓库中文说明：[README-zh.md](https://github.com/xieyulai/steer/blob/main/README-zh.md)。

## 适合谁，不适合谁

**适合**：手里已经有能跑的训练入口；想在自己课题上做 auto-research；需要把改动、分数和复查留下来。

**不太适合**：还停留在想法、没有可跑的训练；或者主要想要「从选题一键写到投稿」的全自动流水线。
